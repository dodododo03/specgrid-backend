# 데모 데이터

`python -m scripts.seed_demo --base-url <사이트 주소>` 로 데모 판매자 3명과 상품 18개를 만듭니다.
자세한 사용법은 `scripts/seed_demo.py` 맨 위 설명을 보세요.

## 사진 출처

`photos/` 의 사진은 모두 [Wikimedia Commons](https://commons.wikimedia.org/)에 자유 라이선스
(CC0 / CC BY / CC BY-SA)로 올라온 사진의 1600px 버전입니다. 원본 링크, 저작자, 라이선스는
`photo_credits.json` 에 있고, 상품 설명 끝에도 `(사진: 저작자, 라이선스, Wikimedia Commons)` 로 표시됩니다.
사진 속 제품 상태·가격·설명은 데모용으로 지어낸 내용이며 사진 저작자와 관계없습니다.
